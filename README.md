## Project Overview

This project is a fully responsive personal portfolio website developed using HTML5, CSS3, and JavaScript. The website showcases personal information, education, technical skills, projects, and contact details in a professional and visually appealing format.

---

## Features

* Responsive design for desktop, tablet, and mobile devices
* Fixed navigation bar
* Smooth scrolling navigation
* Professional home section with profile image
* Education section with academic details
* Skills section with technology cards
* Projects section with GitHub repository links
* Contact section with LinkedIn, GitHub, Instagram, Gmail, and phone number
* Resume view button
* Hosted online using GitHub Pages

## How to Use

1. Download or clone the project.
2. Open the project folder.
3. Edit the content in `index.html` as needed.
4. Replace `profile.jpg` with your own profile photo.
5. Replace `Vasini_resumee.pdf` with your resume.
6. Open `index.html` in a browser.
7. Customize links and content as required.
